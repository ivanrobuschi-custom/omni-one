# Sostituzione POS

È possibile sostituire un dispositivo POS installato sul campo con un nuovo dispositivo (**stesso modello**) tramite la seguente procedura.

## Procedura da eseguire sul nuovo dispositivo

1. Accendere il registratore di cassa premendo il tasto **ON/OFF**. Nel caso di utilizzo di un DIS-PAY, accenderlo collegando l'adattatore esterno fornito alla rete elettrica: il dispositivo si accenderà autonomamente.
2. Sul display cliente (dispositivo POS) premere entro **30 secondi** sul display. Se il dispositivo è acceso e il display è in standby, in modo equivalente, premere due volte nell'angolo in alto a sinistra del display.
3. Alla schermata *Inserisci Password* inserire la password `mm1gg7` (dove `mm` = mese corrente e `gg` = data odierna) e premere **OK**.
4. Premere sul tasto **IMPOSTAZIONI**.
5. Tramite la tastiera numerica inserire la seguente password: `pax9876@@.` e premere **OK**.
6. Premere sul tasto **APP E NOTIFICHE**.
7. Premere sul tasto **MOSTRA TUTTE LE APP**.
8. Premere sul tasto **MAXSTORE**. Viene visualizzato il messaggio: *Accesso fallito, il terminale (SN:XXXXXX) non risulta registrato*.
9. Premere sul tasto **APRI**.
10. Premere sull'icona in alto a destra e poi sul tasto **SOSTITUZIONE**.
11. Scansionare il numero di serie (SN) del dispositivo **da sostituire** oppure digitarlo manualmente tramite tastiera.
12. Premere sul tasto **PROSSIMO**.
13. Premere sul tasto **SOSTITUZIONE**. Il sistema completerà automaticamente l'operazione.

!!! note "Esito"
    Il nuovo dispositivo risulta correttamente registrato su MAXSTORE. Le applicazioni preinstallate di fabbrica rimangono invariate; vengono inoltre scaricate automaticamente le eventuali applicazioni aggiuntive già presenti sul dispositivo sostituito.

    Sul dispositivo sostituito viene visualizzato il messaggio: *ATTENZIONE: il terminale è stato sostituito.*
